# Medical Insurance Cost Prediction Using Machine Learning - ML Type - Regression

## Overview

This project applies machine learning techniques to an insurance dataset to explore the factors associated with insurance costs and demonstrate predictive modelling.

The project follows a practical workflow from data exploration and preparation through model training, prediction, and evaluation.

## Objectives

* Explore the insurance dataset.
* Understand relationships between variables.
* Prepare data for machine learning.
* Train a predictive model.
* Estimate insurance costs.
* Evaluate model performance.

## Machine Learning Workflow

```text
Insurance Dataset
       ↓
Data Exploration
       ↓
Data Cleaning
       ↓
Feature Preparation
       ↓
Model Training
       ↓
Cost Prediction
       ↓
Model Evaluation
```
