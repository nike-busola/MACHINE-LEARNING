# Mobile Phone Price Range Prediction - ML Type - Classification

## Overview

This project uses machine learning to predict the **price range of mobile phones** based on their technical specifications.

The project demonstrates how product attributes can be transformed into machine-learning features and used to build a predictive classification model.

## Objectives

* Explore mobile phone specifications.
* Prepare the dataset for machine learning.
* Identify relevant features.
* Train a classification model.
* Predict mobile phone price categories.
* Evaluate model performance.

## Key Features

The dataset contains mobile-device specifications that can be used to distinguish between different price categories.

```text

       ↓

       ↓
```
