# Student Score Prediction Using Machine Learning - ML Type - Predictive Modelling

## Overview

This project explores predictive modelling using a student score dataset. The notebook demonstrates how machine learning can be applied to identify relationships within structured data and generate predictions.

## Objectives

* Explore and understand the score dataset.
* Prepare data for machine learning.
* Identify relevant predictive variables.
* Train a machine learning model.
* Generate predictions.
* Evaluate model performance.
