# Watermelon Price Prediction - ML Type - Regression

## Overview

This project demonstrates the fundamentals of **Simple Linear Regression** using Python and Jupyter Notebook.

The Watermelon dataset is used to explore a predictive relationship between variables and demonstrate how a regression model can be trained and used to generate predictions.

## Objectives

* Understand the concept of simple linear regression.
* Load and explore a dataset using Python.
* Identify the relationship between variables.
* Train a linear regression model.
* Generate predictions.
* Evaluate the model's performance.
* Visualize the regression relationship.
